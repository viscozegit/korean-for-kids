# 한글 떼기 - 와이어프레임 (iPad 가로 기준)

> iPad 가로 (약 1180 × 820pt) 기준. 모든 버튼은 최소 88pt 이상.
> 글자(ㄱ, ㅏ 등)는 실제로는 화면 짧은 변의 30~40% 크기.

---

## 2. 홈 화면

```
┌────────────────────────────────────────────────────────────┐
│  ⭐ 12                                              ⚙️ (3s) │  ← 별 카운트 / 부모메뉴
│                                                            │
│             안녕!  오늘도  같이  놀자                       │
│                                                            │
│                                                            │
│   ┌──────────────────┐      ┌──────────────────┐          │
│   │                  │      │                  │          │
│   │       🐯         │      │       🦋         │          │
│   │                  │      │                  │          │
│   │   자 음  배 우 기 │      │   모 음  배 우 기 │          │
│   │                  │      │                  │          │
│   │   ㄱ ㄴ ㄷ ㄹ ...│      │   ㅏ ㅑ ㅓ ㅕ ...│          │
│   │                  │      │                  │          │
│   └──────────────────┘      └──────────────────┘          │
│                                                            │
│                                                            │
│         🎁  이어서  하기  (마지막: ㄷ)                      │  ← 진도 있으면 표시
│                                                            │
└────────────────────────────────────────────────────────────┘
```

**동작**
- 자음/모음 카드 터치 → 자모 선택 화면
- "이어서 하기" 터치 → 마지막 학습 자모로 바로 이동
- ⚙️는 3초 길게 눌러야 진입 (아이 오터치 방지)

## 4. 학습 화면 1단계: 보고 듣기

```
┌────────────────────────────────────────────────────────────┐
│  ←  돌아가기                  ●○○  1/3                      │  ← 진행 점
│                                                            │
│                                                            │
│              ┌──────────────────┐                          │
│              │                  │                          │
│              │                  │                          │
│              │       ㄱ         │     ← 거대한 글자          │
│              │                  │                          │
│              │                  │                          │
│              └──────────────────┘                          │
│                                                            │
│                    " 기 역 "                                │  ← TTS 텍스트 동기화
│                                                            │
│                                                            │
│       🚂  기 차                       🔊  다시  듣기        │
│                                                            │
│                                                            │
│                                       다음  →               │
└────────────────────────────────────────────────────────────┘
```

**동작**
- 진입 시 자동으로 "기역" → 1초 → "기차" TTS 재생
- 🔊 버튼: 다시 들려주기
- "다음 →" 터치: 2단계로

## 10. 디자인 참고

| 요소 | 사이즈 (iPad 가로 기준) |
|---|---|
| 메인 글자 (학습 화면) | 약 360pt |
| 카드 글자 (그리드) | 약 120pt |
| 버튼 최소 터치 영역 | 88 × 88pt |
| 본문 안내 텍스트 | 32~40pt |
| 별 아이콘 | 48pt |
| 여백 (화면 가장자리) | 48~64pt |
